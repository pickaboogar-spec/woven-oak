# Woven Oak v0.1.0-beta.6 — Rough Beta

**Status: ROUGH BETA** — expect rough edges, and please report
them. Testers: phone model, Android version, what worked, what
broke, via GitHub Issues.

## The pads teach themselves again

One night of field testing settled it: a pad has to say how to
drive it, right on the pad. Beta.4's labels were clipped,
beta.5's numbers-only pads were clean but silent. Beta.6 is
the middle Paul asked for:

Each pad shows its **number, big**, and underneath, in small
type that fits the pad whole:

**Tap to record · tap to stop**
**Hold to clear**

You still read state at a glance — red recording, green
looping, the pad breathing while it plays, the play-together
row showing what's sounding.

Everything else from beta.5 stands: the chant fits your words
to the beat across four styles, and building a chant stops the
pads so it stands alone.

## Releases

Per the project's release policy, only the two most recent
versions stay downloadable: beta.6 (current) and beta.5
(fallback). Beta.4 is retired with this release. Same signing
key throughout — beta.6 installs straight over the top.
